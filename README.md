## Hi there

I'm Christian, a fresh graduate and web developer based in the Philippines. I approach development from a systems engineering perspective — translating business requirements into technical architecture and leveraging AI-assisted tools to bring them to life efficiently.

> *I focus on understanding the problem deeply before reaching for the tools. The technology should serve the solution, not the other way around.*

This repository holds the source code for my personal portfolio. It documents the real-world projects I've worked on, the problems they solved, and the reasoning behind every technical decision. If you're an employer, a collaborator, or just someone curious about my work — the live site is the best place to start.

- **Project Case Studies** — In-depth breakdowns of each project, covering the challenge, my approach, and the measurable outcomes

- **Working Contact Form** — Reach out directly through the site; messages go straight to my inbox
